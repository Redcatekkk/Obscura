# 📐 obscura.deck — Implementation Plan

> Port of the NULLBYTE web mockup into a fully-functional **Tauri 2 desktop app**.
> Every module is real, every test is real, the only thing that isn't real is the *Discord side* (we run a local simulation engine instead — Discord ToS forbids self-bots).

---

## 🎯 Goal in one sentence
Ship a polished cross-platform desktop app that **looks pixel-identical** to the provided mockup, where all 50 modules operate **end-to-end against a local Simulation Engine** (with an optional, opt-in, sanctioned **bot-token** adapter using the official Discord API), with **full test coverage** and **signed release artifacts** for macOS, Windows, and Linux.

## 🛡 Safety boundary (non-negotiable)

- ✅ Build a self-contained **Simulation Engine ("simverse")** in Rust that emits realistic events (messages, joins, deletes, VC, ratelimits). All 50 modules observe/act on this stream.
- ✅ Provide an optional `bot_adapter` feature using `serenity` —  Disabled by default. Visible under Settings → *"Connect a real bot (optional)"*.
- ✅ Show a first-run modal explaining the simulation-only nature + keep the sidebar disclaimer card.

## 🧠 Backend architecture

### Event bus
```rust
pub enum DeckEvent {
    Log(LogLine),
    ModuleStateChanged { id: ModuleId, enabled: bool },
    KpiTick(KpiSnapshot),
    SimEvent(SimEvent),       // MessageCreate, MessageDelete, MemberJoin, VcJoin, ...
    BotAdapter(BotAdapterEvent),
}
pub struct Bus(tokio::sync::broadcast::Sender<DeckEvent>);
```
Modules subscribe, process events against their per-module config (SQLite), emit new events. Logs are forwarded to the FE via `app.emit("deck:event", ...)`.

### SQLite schema
- `modules(id PK, enabled, config JSON, updated_at)`
- `logs(id, ts, level, source, text)` — rolling 10k cap
- `kpis(ts, name, value)` — 24h rolling, 1s granularity
- `simverse_{users,guilds,channels,messages}`
- `snapshots` — guild backups (f48)
- `settings(key, value)`

### Tauri commands (typed via `tauri-specta`)
```
modules_list() -> Vec<ModuleSummary>
modules_set_enabled(id, enabled)
modules_get_config(id), modules_set_config(id, json)
modules_trigger_test(id)
kpi_recent(window) -> KpiSeries
logs_recent(limit) -> Vec<LogLine>
sim_status(), sim_set_intensity(0..=100)
settings_get(key), settings_set(key, value)
bot_adapter_connect(token), bot_adapter_disconnect(), bot_adapter_status()
deck_export_snapshot() -> PathBuf
```

### Module trait
```rust
#[async_trait]
pub trait Module: Send + Sync {
    fn id(&self) -> &'static str;
    fn category(&self) -> Category;
    async fn on_event(&self, ev: &DeckEvent, ctx: &ModuleCtx) -> Result<()>;
    fn default_config(&self) -> serde_json::Value;
}
```

### The 50 modules — concrete behavior against simverse
Treat the existing `functions.js` as the authoritative ID/category/desc table. Examples:
- **f01 Message Sniper** → on `SimEvent::MessageDelete` write `sniped_messages` row + emit `Log`.
- **f02 Regex Auto-Reply** → on DM `MessageCreate` matching user regex, emit operator reply event + log.
- **f03 Status Rotator** → cron every N seconds, cycle presence.
- **f17 Stealth Mode** → toggle hides operator from simverse mutuals computation.
- **f23 VC Time Logger** → accumulate per-channel duration on VC events; feeds f24 pie chart.
- **f37 Desktop Toast** → real OS toast via `tauri-plugin-notification` (genuinely useful regardless of sim).
- **f38 Webhook Bridge** → outbound `reqwest` POST to user URL (ToS-safe, real).
- **f41 Theme Forge** → writes `settings`, FE subscribes, re-themes live.
- **f48 Guild Snapshot** → gzipped JSON of simverse guild tree.
- **f50 Settings Sync** → export/import all configs as one JSON file.

**All 50** must be implemented and observable in the syslog when toggled.

### Simverse
Background tokio task. ~12 fake guilds · ~80 users · ~40 channels · ~6 VCs. Emits events on a Poisson schedule scaled by `sim_set_intensity`. Logs seeded from `data/sim_corpus.ron`. Deterministic with `--seed` for tests.

## 🎨 Frontend port rules

- Port the existing React mockup **1:1** to TSX. Preserve every `data-testid`.
- Copy `styles/index.css` verbatim (fonts, aurora, glass, toggle, holo, chrome, marquee, grain).
- Replace local mock state with TanStack Query hooks against typed `invoke()` wrappers.
- `TerminalFeed` subscribes to `deck:event` via `app.listen` — no polling.
- `Toggle` calls `modules_set_enabled` with optimistic UI.
- `ConfigModal` Settings tab is generated dynamically from each module's `default_config` schema (react-hook-form + zod inferred from `tauri-specta` types).
- `MasterControl` Engage/Disengage calls `sim_set_intensity(0|50)`.
- ⌘K / Ctrl+K global shortcut focuses search.
- Light-mode theme toggle actually swaps CSS variables (currently only icon swaps).

## ✅ Testing requirements

### Rust unit + integration
- Each module: happy / disabled / malformed config / edge case.
- Simverse: deterministic seeds, `proptest` invariants (no panics @ 100k events, event counts within bounds).
- IPC: round-trip JSON, error paths, permission checks.
- DB: idempotent migrations, all repos covered.

### Frontend unit
- Components render & dispatch correct IPC calls (mocked).
- Stores: reducers & selectors fully covered.

### E2E (tauri-driver + WebdriverIO + screenshot diff)
1. Cold boot → first-run disclaimer modal → dismiss → main UI.
2. Toggle `f01` ON → trigger sim → log row appears within 2s.
3. Open `f02` modal → set regex `/gn/i` → apply → simverse `"gn"` → reply log line.
4. Search `vc` → exactly 5 cards.
5. Sidebar "Privacy" → exactly 5 cards.
6. ⌘K → search input focused.
7. Disengage → KPI sparklines flatline, syslog shows offline marker.
8. Theme Forge swap → CSS vars update without reload.
9. Settings Sync export → re-import → state preserved.
10. Webhook Bridge → POST to local httptest → body matches schema.

### Performance gates (CI assertions, release build)
- Cold boot to first paint **< 800 ms**.
- Steady-state RAM **< 180 MB** @ 50 modules ON, intensity 50.
- CPU **< 6 %** on M1 / Ryzen 5 steady state.

### CI matrix (GitHub Actions, macos-14 / ubuntu-22.04 / windows-latest)
```
- cargo fmt --check && cargo clippy -- -D warnings
- cargo test --workspace --all-features
- pnpm i && pnpm lint && pnpm typecheck && pnpm test
- pnpm tauri build         (smoke on macOS PRs; full matrix on tags)
- upload e2e screenshots as artifacts
```
